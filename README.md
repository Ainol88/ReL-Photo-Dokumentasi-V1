# ReL Photo Dokumentasi V1

Aplikasi Android asas untuk membuat dokumentasi foto dan menghasilkan PDF A4 dengan maksimum dua foto pada setiap halaman.

## Kandungan
- Tambah foto melalui galeri atau kamera.
- Masukkan tajuk, tarikh, lokasi dan keterangan bagi setiap foto.
- Simpan draf pada peranti.
- Jana PDF A4 dengan dua foto setiap halaman.

## Struktur projek
Pastikan kandungan folder projek dimuat naik terus ke akar repositori GitHub. Folder `app`, fail `settings.gradle`, `build.gradle`, `gradle.properties`, dan folder `.github` mesti berada di aras teratas repositori.

## Bina APK
1. Buka tab **Actions** pada repositori GitHub.
2. Pilih **Build ReL Photo Dokumentasi APK**.
3. Tekan **Run workflow** pada branch `main`.
4. Selepas berjaya, muat turun artifact `ReL-Photo-Dokumentasi-APK`.

APK yang dijana ialah debug APK untuk ujian/pemasangan peribadi.
